## ✨ Features

- 📊 **Reach & Impressions Analytics**: Displays exact total reach (e.g., 1.95 Billion Views), Reels creation volume (e.g., 3.8M Reels), daily growth surge (+42.5M views/day), and 7-day trajectory curves.
- 🎵 **Interactive Audio Engine**: 30-second real audio snippet player with animated waveform visualizer, seek bar, loop toggle, and floating bottom mini-player.
- 📱 **Direct Instagram Integration**: 1-click "Use on Reels" buttons that jump straight to the Instagram Reels audio page or search keyword.
- 🧮 **Creator Reach Predictor**: Input follower count and niche to simulate projected reel impressions, explore page ratio, and optimal video duration.
- 🌐 **Global Music Discovery**: Search any song on Apple Music & Instagram's catalog with dynamic reach simulation and instant audio playback.
- 🎨 **Instagram Neon Aesthetic**: Dark mode UI inspired by Instagram Reels, Spotify, and glassmorphic micro-interactions.
- ⚡ **Zero-Dependency Fast Loading**: Static web architecture ready for instant CDN caching on Vercel.

## 🛠 Local Setup

```bash
git clone https://github.com/srijankulal/instagram-trending-reach.git
cd instagram-trending-reach
npx serve . -l 3000
```
Open `http://localhost:3000` in your browser.
